# Архив публикаций

Трекер научных публикаций arXiv по выбранным темам. Заголовки и описания переведены на русский язык.

Сборки и зависимостей нет. `index.html` — только отображение, данные лежат в `data/`:

| Файл | Что внутри |
|---|---|
| `data/publications.json` | массив публикаций |
| `data/stats.json` | статистика сканирований: `{ "scans": N, "lastScan": "…" }` |
| `data/topics.json` | темы по умолчанию |

Страница загружает JSON через `fetch`, поэтому её нужно открывать через веб-сервер, а не двойным кликом:

```
python3 -m http.server
# затем откройте http://localhost:8000
```

или через GitHub Pages.

## Возможности

- список тем слева (добавление/удаление, хранится в `localStorage` браузера; по умолчанию — из `data/topics.json`);
- поиск по названию, описанию, номеру, ссылке и категории;
- постраничный вывод по 5 записей, новые сверху;
- статистика сканирований.

## Формат публикации

```json
{
  "id": "2610.40325",
  "url": "https://arxiv.org/abs/2610.40325",
  "title_ru": "Заголовок публикации",
  "published": "29.10.2026",
  "desc_ru": "Краткое описание",
  "category": "Трансформеры"
}
```

`published` — в формате ДД.ММ.ГГГГ, `category` — название темы из `data/topics.json`.
Дубли по `id` на странице отбрасываются автоматически.

## Скилы агента

Конвейер обновления архива описан скилами в формате [Agent Skills](https://agentskills.io) (`SKILL.md`):

| Скил | Что делает |
|---|---|
| `arxiv-search` | ищет новые публикации на arXiv по темам |
| `paper-ru-summary` | переводит названия и абстракты на русский |
| `archive-update` | добавляет записи в `data/publications.json`, обновляет `data/stats.json`, коммитит |
| `telegram-notify` | отправляет подборку в Telegram (нужны `TG_BOT_TOKEN` и `CHAT_ID`) |

Скилы лежат в `.agents/skills/` — общей папке, которую читают разные агенты.
`.claude/skills` — символическая ссылка на неё для Claude Code.
