# Архив публикаций

Трекер научных публикаций arXiv по выбранным темам. Заголовки и описания переведены на русский язык.

Всё приложение — один файл `index.html` без зависимостей и сборки: откройте его в браузере.

## Возможности

- список тем слева (добавление/удаление, хранится в `localStorage` браузера);
- поиск по названию, описанию, номеру, ссылке и категории;
- постраничный вывод по 5 записей, новые сверху;
- статистика сканирований.

## Как добавлять публикации

Записи хранятся в массиве `PUBS` внутри `index.html` (между комментариями
`===== ПУБЛИКАЦИИ =====` и `===== КОНЕЦ БЛОКА ПУБЛИКАЦИЙ =====`):

```js
{
  "id": "2610.40325",
  "url": "https://arxiv.org/abs/2610.40325",
  "title_ru": "Заголовок публикации",
  "published": "29.10.2026",        // ДД.ММ.ГГГГ
  "desc_ru": "Краткое описание",
  "category": "Трансформеры"        // совпадает с названием темы
}
```

Дубли по `id` отбрасываются автоматически. Статистика сканирований — в объекте `STATS`.
